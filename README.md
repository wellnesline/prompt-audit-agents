# prompt-audit-agents

Three reusable Claude Code subagents for auditing generative web apps: prompt bias and contradictions, unused/dead code, and Playwright-based E2E checks.

生成系の Web アプリを検査するための Claude Code サブエージェント 3 本です。コードではなく Markdown のエージェント定義です。

## 概要

AI を組み込んだアプリは、プロンプトの例文が出力を同じ方向に寄せたり、設定画面の値が実際の出力に効いていなかったりします。通常のテストでは見つかりにくいこの種の問題を、3 つの役割に分けて検査します。親のエージェントが検査の切り口を指定して並列に起動し、それぞれが行番号付きの Markdown レポートを返す使い方を想定しています。

## 含まれるエージェント

| ファイル | 役割 | ツール |
|---|---|---|
| `prompt-bias-auditor.md` | プロンプトの静的監査。バイアス 4 類型（例文模倣 / 分野ハードコード / 属性ステレオタイプ / 既定値の一律化）と、プロンプト内の論理破綻・指示矛盾を検出する | Read, Grep, Glob, Bash, Write |
| `unused-audit.md` | 未使用・死蔵の検出。「本来使うべきなのに使われていないもの」と「もう不要なもの」を、モデルと使用箇所・API と呼び出し・UI 入力と実効果の相互参照で洗い出す | Read, Grep, Glob, Bash, Write |
| `webapp-e2e-tester.md` | Playwright とデータファイル・API を使った E2E 検証。1 回の起動で 1 つの切り口（論理破綻、UI のばらつき、デバッグ表示の漏れなど）を担当する | Read, Write, Bash, Grep, Glob |

## 設計のポイント

- **コードは変更しない**: 監査役は検出と修正案の提示だけを行い、実装は親が判断します。
- **根拠の提示を必須にする**: 指摘には行番号の引用を付けさせ、推測だけの指摘を減らします。
- **切り口を分けて並列化**: E2E 検証は 1 エージェント 1 切り口にして、親が複数同時に起動し、全体をカバーします。
- **プロジェクト非依存**: 特定のアプリを前提にせず、対象ルートや URL、出力先を親から受け取ります。

## 使い方

3 つの `.md` を `.claude/agents/` に置き、Claude Code から対象ファイル群・出力先・（E2E なら）URL と切り口を指定して起動します。E2E 検証には対象アプリの起動と、Playwright が使える環境が必要です。

環境変数・外部サービスの鍵は使いません。

## 制限事項（閉包）

- **同梱していない依存**（0 件）: コード上の import はありません（Markdown のみ）。E2E 検証を行うには、対象のアプリ本体と Playwright（および Chromium）が別途必要です。
- 文中の例（ローカルのアドレス、設定名など）は説明用の一例です。
- 関連する他の公開リポジトリ: エージェント定義の別例は `claude-code-agent-patterns` にあります。
- 検出結果は静的な読み取りに基づく候補です。修正前に実行して確かめることを前提にしています。
